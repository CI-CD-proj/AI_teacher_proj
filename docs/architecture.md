# Mektep AI — MVP архитектура

Мақсат: Қазақстан мектебінде мұғалім материал мен тест дайындайды, оқушы аккаунтсыз тест тапсырады, ашық жауаптарды Gemini қазақша талдайды.

## Рөлдер

- **Мұғалім** — email + құпиясөз (JWT). Жоспар/силлабус жүктейді, тест құрады, нәтижені көреді.
- **Оқушы** — тіркелмейді. Тест коды + аты-жөні.

## Ағын

1. Мұғалім тест құрады (жабық + ашық сұрақтар, ашыққа үлгі жауап).
2. Оқушы `/t/{CODE}` арқылы кіреді.
3. Жабық сұрақтар rule-based тексеріледі.
4. Ашық сұрақтар `ai_analyzer.py` арқылы Gemini-ге JSON-схемамен кетеді.
5. Оқушы мен мұғалім: не қате, неліктен, қайдан бастау, нені оқу.

## Стек (MVP)

- FastAPI + SQLAlchemy + SQLite
- Gemini Flash (`GEMINI_API_KEY`)
- Бір процессте HTML/JS UI (`backend/static`) — Node керек емес

V1-ге көшкенде: PostgreSQL, Redis/кезек, Next.js, мұғалім аналитикасы.
